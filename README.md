# Note Bridge — 0.4.0 (experimental)

Плагин Obsidian для синхронизации локального хранилища с обычными файлами Google Drive и персональный OAuth-сервис на Cloudflare Workers.

Экспериментальный личный плагин. Пользователь подтвердил вход Google и обмен заметками на iPhone. Изменения 0.4.0 проверены автоматически; реальная скорость и интерфейс обновления на телефоне требуют проверки. Подробности — [docs/STATUS.md](docs/STATUS.md).

## Что реализовано

- Настройки на русском, вход через браузер, завершение подключения из Obsidian.
- Ключ устройства в Obsidian SecretStorage (Obsidian >= 1.11.4); access token только в памяти.
- Ручной синк, предпросмотр, необязательный синк по событиям/таймеру и возвращению в приложение.
- Рекурсивное чтение обычных папок Drive, Markdown и вложений, включая добавленные извне.
- Сравнение SHA-256 с локальной базовой версией; часы устройств не определяют победителя.
- Передача новых файлов в обе стороны и обновление текстовых заметок.
- Конфликтные копии в `Note Bridge Conflicts/`; оригиналы не перезаписываются при конфликте.
- Проверка версии перед записью; If-Match/ETag для обновления через Drive API v2.
- Снимки содержимого до замены в `.note-bridge-history` в папке Drive.
- Локальный журнал последних 500 событий; последние 100 показаны в интерфейсе.
- OAuth: PKCE, браузерный state-cookie, одноразовая выдача ключа устройства, разрешённый Google-аккаунт, код подключения владельца, AES-GCM для refresh tokens в D1.

## Поведение и ограничения

1. Переименования после установки 0.2.0 передаются с сохранением ID. Новые локальные удаления передаются автоматически, если версия Drive не менялась. Спорные удаления и старые дубликаты разбираются в окне «Конфликты и удаления». Передача переименования может блокироваться при одновременных правках; содержимое сохраняется для ручного разбора.
2. Есть выбор целой версии и построчное сравнение Markdown/TXT с выбором отдельных блоков и редактируемым результатом. Автоматического трёхстороннего слияния и интерфейса отката истории нет.
3. Новые вложения копируются, но изменённые существующие локальные двоичные файлы не перезаписываются автоматически. Лимит — 10 МиБ на файл.
4. После первоначального индекса используются Changes API и локальный кэш хешей. Полная сверка остаётся при структурных изменениях папок и восстановлении индекса. Автосинк — после 30 секунд без правок, не чаще раза в минуту.
5. `.obsidian`, скрытые файлы и папки, служебная история и конфликтные копии исключены. Пустые папки не синхронизируются.
6. Только обычные файлы My Drive. Google Docs/Sheets/Slides и ярлыки не конвертируются; обнаружение такого объекта останавливает сверку. Shared Drives пока не поддержаны.
7. При одинаковых путях, различиях только в регистре/Unicode или неподдерживаемых именах синк останавливается. Полный список правил — `core/sync.ts`.
8. Google Drive допускает одинаковые имена. При гонке создания могут остаться два файла/папки: плагин остановится, но не будет сам удалять один из них.
9. If-Match нужно проверить на настоящем Drive, включая намеренную гонку. При отсутствии ETag запись блокируется. Предварительная проверка версии сама по себе не является транзакцией.
10. История пока не очищается автоматически. Неизменившиеся повторные конфликты не создают повторных снимков. Это расходует место Drive. История — не независимая резервная копия.
11. Нет гарантии фонового выполнения на iOS. Приложение нужно держать открытым до завершения синка.
12. Вход нужно закончить в рамках текущего запуска плагина (10 минут); после выгрузки приложения начать заново. Не копируйте data.json/SecretStorage между устройствами.
13. Не запускайте параллельно другой синхронизатор для того же локального хранилища.

## Структура

- `core/` — независимый механизм сравнения и синхронизации.
- `plugin/` — интерфейс Obsidian и адаптер Drive.
- `auth-service/` — Worker, SQL-схема, конфигурация Cloudflare.
- `tests/` — проверки конфликтов, отказов, условных записей, OAuth и шифрования.
- `dist/note-bridge/` — собранные main.js, manifest.json, styles.css.
- `dist/auth-worker.mjs` — собранный Worker.
- `docs/SETUP.md` — подключение Google, установка и проверка.
- `docs/STATUS.md` — точное состояние готовности и следующая работа.

## Разработка

Node.js 24:

```sh
npm ci
npm run check
```

`npm run check` проверяет TypeScript, запускает тесты и собирает оба компонента. Версии зависимостей зафиксированы в package-lock.json. Worker types сгенерированы Wrangler, включены в проект. Для их повторной генерации создать локальный `.dev.vars` по примеру и выполнить `npm run worker:types`; реальные секреты не коммитить.

## Установка

На компьютере: скопировать содержимое `dist/note-bridge` в `<vault>/.obsidian/plugins/note-bridge`, перезапустить Obsidian и включить плагин. Использовать новое тестовое хранилище.

На iPhone: установить или обновить через BRAT, репозиторий `Muhozhukov/note-bridge`, версия `0.4.0`. Корневой manifest.json и файлы релиза формируются сборкой. Архив проекта сам по себе не является ссылкой для BRAT.

## Безопасность

Сервис получает полномочия полного scope Drive, чтобы видеть файлы, добавленные другими приложениями. Выбранная папка — ограничение кода плагина, не OAuth-граница. Используйте только личный Google-аккаунт, разрешённый в `ALLOWED_EMAIL`.

Содержимое заметок передаётся напрямую между плагином и Google. Worker видит OAuth-коды/токены, хранит refresh token зашифрованным, а ключи устройств — в виде SHA-256. Компрометация Worker и ключа шифрования может раскрыть доступ к Drive. Шифрование D1 не является сквозным шифрованием заметок.

Никакие секреты не должны попадать в GitHub, ссылки, журналы или архив проекта. Логи запросов Worker намеренно отключены, поскольку OAuth callback содержит код в query string. Ключ устройства живёт максимум 180 дней; при истечении подключить устройство снова. Отключение устройства удаляет его серверную запись; уже выданный краткосрочный access token может действовать до истечения. Полностью отозвать Google-разрешение можно в настройках аккаунта Google.
