Privacy Policy

This policy describes the Note Bridge plugin, its personal Cloudflare authorization service and this project website. The maintainer is reachable through the project issue tracker. If you use a separately operated authorization service, contact its operator about its actual configuration and data handling.

Data accessed and why

  • Google account: the authorization service requests openid and email to obtain and verify an email address and compare it with its allowed-account configuration.
  • Drive files: the plugin requests https://www.googleapis.com/auth/drive to synchronize existing and externally added files. It processes paths, file IDs, versions, metadata and content in the configured folder, including conflict copies and history snapshots. This is full Drive authorization; the selected folder is an application-level restriction, not a Google-enforced permission boundary.
  • Credentials: the service exchanges authorization codes and uses Google access and refresh tokens. It never asks for or stores your Google password.

Where data is stored

Local notes, synchronization indexes, hashes, common-version caches, conflict copies and diagnostic records are stored on your device. Cloud copies and revision snapshots are stored in your Google Drive. The plugin sends note contents directly to Google Drive, not through the authorization Worker.

The Cloudflare Worker stores encrypted Google refresh tokens, hashed device keys and connection timestamps in Cloudflare D1. Temporary login sessions include cryptographic challenges and expire after 10 minutes. Device grants currently expire after 180 days; scheduled cleanup removes expired records. A refresh token may become invalid earlier under Google's rules.

Device credentials and unfinished login proofs are stored through Obsidian SecretStorage. Google access tokens are held in plugin memory. The allowed-email list is a server configuration value, not a public list.

Use and sharing

Google user data is used only to provide authorization, synchronization, conflict handling, history and user-requested diagnostics. It is not sold, used for advertising, used to train generalized AI models or shared with data brokers. Note Bridge's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google provides account authorization and Drive storage. Cloudflare provides the authorization service and its database. If this website is deployed on Firebase Hosting, Google also delivers these static pages. These providers may process network and operational information under their own policies. Other people can access shared Drive folders according to permissions you grant. Separate tools you choose to connect, such as an AI assistant with its own Drive access, are outside Note Bridge and governed by their own permissions and policies.

Diagnostics, cookies and website

The plugin keeps local event history and performance measurements. Event history can contain file paths and error details. Performance reports contain timings, counts and payload sizes, not note content, file names, Drive IDs or credentials. Exports are local files and are not automatically sent to the maintainer; review them before sharing.

The authorization flow uses a short-lived secure browser cookie to bind Google's response to the login attempt. This static website adds no analytics scripts, advertising or tracking cookies. Worker request logging is disabled in the project's deployment configuration; hosting providers may still maintain their own operational records.

Disconnecting and deleting data

Use “Выйти из аккаунта” in the plugin to remove local connection credentials and request deletion of the current server-side device grant. If the server cannot be reached, local logout succeeds but server deletion is not confirmed. Revoke the application's Google access in Google Account connections to invalidate its Google authorization. Revocation does not itself delete all stored encrypted records; contact the service operator for server-side deletion. Expired records are also subject to scheduled cleanup.

Logging out does not delete notes, Drive history, local indexes or diagnostic exports. Remove those separately using Obsidian, your device's file manager or Google Drive. Changes to the allowed-email list do not revoke existing device grants. Keep backups before removing synchronization state.

Security and changes

Connections use HTTPS and refresh tokens are encrypted before database storage. This is not end-to-end encryption of notes: Google Drive and authorized devices can access note content. No system can guarantee absolute security. Updates to this policy are published here with a revised date.

For privacy requests, contact the configured service operator or the maintainer. Do not post tokens, pairing codes, private notes or other secrets in public issues.
