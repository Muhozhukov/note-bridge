# Note Bridge 0.1.1 — experimental

Обновление для BRAT: ускорение первого скачивания и управление синхронизацией на телефоне.

## Изменения

- Скачивание файла с SHA-256 из Drive: один GET с проверкой содержимого вместо трёх запросов. Проверка ETag перед перезаписью Drive сохранена.
- При первом скачивании больше не загружаются обратно в Drive снимок и JSON на каждый файл. Снимки перед заменой существующего файла и обеих сторон конфликта сохранены. Журнал загрузок остаётся на устройстве. Это история перед перезаписью, не полный Git-репозиторий.
- Для файлов без SHA-256 сохраняется проверка версии до/после скачивания; проверенные байты временно кешируются (до 20 МиБ), чтобы не скачивать их второй раз в этом запуске.
- До двух повторов чтения при сетевом сбое, тайм-ауте, HTTP 429/500/502/503/504. Записи автоматически не повторяются: сервер мог уже принять запрос.
- Прогресс: этап, текущий файл, обработано/всего, остаток и полоса. Конфликты/удаления считаются обработанными, но требуют проверки; это видно в итоговом статусе и журнале.
- Плавающая кнопка на мобильных устройствах, окно прогресса, команда «Синхронизация и прогресс», пауза.
- Возврат после сворачивания и перезапуск приложения продолжают прерванный синк через новую сверку. Успешные операции сохраняются пофайлово. Ручная пауза требует ручного продолжения.
- Устаревшие пути, которых уже нет с обеих сторон, не создают ложного конфликта регистра с новыми именами. Диагностика показывает оба конфликтующих имени и учитывает имена родительских папок.
- Экспорт локального журнала в JSON без токенов и настроек авторизации. Файл содержит пути заметок; при отправке учитывайте это. Экспорт исключён из локального сканирования.

## Проверка

53 автоматических теста, проверка типов и сборка. Дополнительные тесты проверяют число запросов, контрольную сумму, кеширование, повторы чтения, запрет повтора записи, кириллицу, устаревшие пути, конфликты папок, прогресс и продолжение после паузы.

Пользователь подтвердил OAuth и загрузку/скачивание файлов на iPhone в 0.1.0. Версия 0.1.1 ещё требует проверки интерфейса, скорости и паузы на реальном iPhone. Тесты адаптера используют подменённые ответы Google.

## Ограничения

- Настоящая фоновая синхронизация iOS не реализована: Obsidian нужно держать открытым. Уже отправленный запрос может завершиться при уходе в фон; новые операции приостанавливаются на следующей контрольной точке.
- Тайм-ауты записи показываются как ошибки; после них повторите синк для новой сверки. Автоматически повторяются только безопасные чтения.
- Реальная причина ранее наблюдавшейся ошибки имени без локального журнала не установлена. Кириллица и обычные пробелы поддерживаются. Конечные пробелы/точки, запрещённые символы, дубликаты и активные коллизии регистра блокируют синк до исправления.
- Автоматическое распространение удаления/переименования и слияние конфликтов пока не реализованы. Существующие изменённые двоичные файлы требуют ручной проверки. Лимит файла 10 МиБ.
- Пока выполняется полная сверка; Changes API и параллельные передачи — дальнейшая оптимизация.
- Перезапись через If-Match Drive v2 и редактирование с нескольких реальных устройств ещё требуют отдельной проверки.
