# Note Bridge 0.3.0 — experimental

## Сравнение и объединение

В «Конфликты и удаления» у конфликтующих Markdown/TXT заметок доступна кнопка «Сравнить и объединить изменения».

- Построчное сравнение текущих версий телефона и Drive; совпадающий текст можно раскрыть.
- Отличающиеся блоки показываются отдельно с номерами строк: красные «−» строки телефона и зелёные «+» строки Drive. Это направления сравнения, не авторство изменений.
- Для каждого блока нужно явно выбрать телефон или Drive. Без решения по всем блокам переход к результату заблокирован.
- Предпросмотр результата — редактируемый текст: можно совместить части строк или дописать свой вариант перед сохранением.
- Сохранение повторно сверяет хеши обеих версий, ID и версию Drive. Устаревшее сравнение не перезаписывает новые правки.
- Перед записью сохраняются обе исходные версии. Сначала условно записывается Drive, затем локальный файл с проверкой ожидаемого содержимого. При частичном сбое новый локальный текст остаётся целым, объединённый результат остаётся в Drive; показана инструкция обновить сравнение. Общая история синхронизации обновляется только после успеха обеих записей.

Это двухстороннее сравнение, а не автоматическое трёхстороннее слияние Git: общий исходный текст не хранится. Лимит сравнения — 200 000 символов на версию и 2 млн ячеек таблицы сравнения. При превышении остаётся выбор целой версии или внешний редактор. Двоичные вложения не сравниваются построчно.

## Интерфейс

- Карточки конфликтов с понятным описанием состояния.
- Удаления, дубликаты, удалённые строки и кнопки корзины выделены красным. Цвет дополнен подписями и подтверждением.
- Журнал: русские названия операций, локальные дата/время, отдельные карточки, фильтр конфликтов/удалений/ошибок. История явно отделена от текущего списка нерешённых проблем.

## Проверка

80 тестов, TypeScript и сборка. Новые тесты проверяют точную реконструкцию строк и переводов строк, пустые версии, Unicode, выбор отдельных блоков, запрет незавершённого выбора, ограничения памяти, резервирование оригиналов, устаревшее содержимое и сохранение пользовательских правок при частичном сбое объединения.

Реальные UI и сохранение объединённой заметки на iPhone ещё требуют проверки. Google API в тестах подменён. Остальные ограничения 0.2.0 сохраняются: нет гарантированной фоновой работы iOS, удаления требуют подтверждения, полная сверка вместо Changes API, лимит файла 10 МиБ. Worker не изменён.
