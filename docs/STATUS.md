# Состояние на 18 октября 2026

Создана экспериментальная сборка 0.1.0. Это исходная реализация для испытаний, не заявление о готовности к ежедневной работе.

## Проверено

- TypeScript: без ошибок.
- 46 автоматических тестов: все пройдены.
- Сборка main.js и Worker: успешна.
- Wrangler deployment dry run: успешен.
- Worker загружен в Cloudflare; D1-схема применена, workers.dev включён.
- /health вернул HTTP 200 с configured=false.
- Запланирована очистка истёкших авторизаций раз в час.

Тесты используют память для файлов, реальный SQLite для SQL-семантики и подменённые ответы Google. Это не тесты настоящего Google Drive, не полноценный D1 runtime test и не запуск Obsidian на iOS.

## Пока не проверено

- Реальный OAuth Google / авторизация iPhone.
- If-Match Google Drive API v2 и совместимость version v2/v3 на реальном API.
- Установка и UI на устройствах.
- Доступность workers.dev из сети пользователя.
- Синхронизация с правками через ChatGPT Work.

## Отличия от первоначальной целевой архитектуры

История сейчас хранится в скрытой служебной папке **внутри** корневой папки Drive и исключена из синка. Это упрощает первую настройку; отдельный соседний корень истории можно добавить позже. UI показывает пока журнал одного устройства. Авторство «ChatGPT» не определяется.

Автоматические удаления и слияние текста намеренно не включены. Изменённые существующие двоичные файлы не скачиваются поверх локальных. Это зафиксированные ограничения alpha, а не завершённые функции.
